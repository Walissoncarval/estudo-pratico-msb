# Estudo Prático MSB - GPS de Estudos CLI

Sistema em linha de comando (CLI) projetado para acompanhamento diário, diagnóstico de desempenho e direcionamento cirúrgico de estudos para concursos públicos.

## 🚀 Como Executar

### Pré-requisitos
- Python 3.8 ou superior instalado.

### Execução
1. Clone o repositório:
```bash
git clone [https://github.com/SEU_USUARIO/estudo-pratico-msb.git](https://github.com/SEU_USUARIO/estudo-pratico-msb.git)
cd estudo-pratico-msb
